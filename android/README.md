# Android

`../build-android.sh` builds `Galebound.apk` with Docker (see the comments at
the top of the script). Package: `com.galebound.online`, landscape, needs the
INTERNET permission only. Saves and settings live in the app's private storage.

On a phone the game shows touch controls (joystick, Jump / Attack / Heavy /
Dodge / Talk / Loot, and Menu / Bag / Chat / Quest buttons); tap windows and
players like a mouse. Bluetooth / USB game controllers work too.
